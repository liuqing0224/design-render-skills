# AI图转3D

## 目标与输入

清晰主体图，透明PNG可用；补充视角；目标格式GLB/OBJ等；单位/尺寸；用途和精度要求。

必须保留：可见轮廓、主要比例、部件关系和参考材质；已给尺寸优先。

关键材料缺失且会改变结果时询问具体缺口；其余按任务语境继续，记录影响输出的重要假设。

## 执行方式

先发现当前可用的建模/重建工具并检查其真实输入输出契约。可以使用本地参数化建模或可用的图转3D能力；没有可用工具时保留未完成状态。图片生成工具不能代替网格导出和模型检查。

## 工作流程

1. 检查主体完整性、遮挡、视角与材质；判断是规则家具、复杂有机体还是整间空间，后者不冒充单体重建。
2. 发现当前可用且获授权的图转3D工具或本地建模环境；不假设存在Evai API或虚构模型生成接口。
3. 规则对象可用参数化建模；复杂对象用实际可用的重建工具。单图隐藏部分明确标为推断，不把整张图贴到平面上冒充模型。
4. 导出目标三维格式，重新打开检查网格、材质、比例、法线和上下方向；检查原视角及至少两个有明显角差的转动视角。

## 提示词或操作规格

将当前需求组织为“目标；输入材料及其角色；修改范围；必须保留；相机/尺度；材料与光照（适用时）；交付格式”。只包含本任务相关项。编辑底图与风格/材质/产品参考必须分开标注。用户明确要求精确保留时，写入可验证的合成或模型操作方案。

示例调用：`使用 $evai-image-to-3d，根据这张透明椅子图片制作GLB模型，真实椅高80厘米，说明背面推断并检查转动视角。`

## 输出与验收

交付可加载模型而非渲染图片；几何非退化平面；材质引用可解析；记录实际模型格式、单位及隐藏面推断。

交付实际产物、关键操作或最终提示词，以及简短验收结果。保留原件，结果另存用户项目目录；只有提示词或中间预览时明确未完成最终产物。记录输入、工具/方法、实际输出尺寸或模型格式、通过项和未通过项，不要求为一次性任务额外建立复杂台账。

## 失败处理与边界

缺少可用建模工具或复杂对象资料不足时，交付输入评估和待建模规格并标记未完成，不伪造模型文件。

修订必须针对具体缺陷；连续两次修订仍有同一核心缺陷时停止盲目重试，保留最佳结果并说明所需补图、模型或工具。用户明确要求继续时更新方案和成本边界。运行外部付费服务、上传用户材料等遵守该任务已有授权；本 Skill 不授权注册、充值、发布或购买模型。没有额外用户请求时不访问 Evai 网站。
