# 图片转提示词

## 目标与输入

图片；希望复现的重点；目标语言；是否需要编辑指令。

必须保留：图中可直接观察到的主体、数量、位置、材料外观和光照。

关键材料缺失且会改变结果时询问具体缺口；其余按任务语境继续，记录影响输出的重要假设。

## 执行方式

直接读取用户提供的材料进行图像理解或文字编写；只在用户进一步要求实际出图时使用图像生成工具。不要为提示词任务制造额外生图成本。

## 工作流程

1. 读取实际图片，按主体、空间、相机、材料、颜色、照明和细节记录可见信息。
2. 将不确定材料写成视觉外观，不从图片断言品牌、尺寸、拍摄设备和隐藏空间。
3. 产出紧凑主提示词；若用于编辑，另列编辑目标与保留项，而非把整张图片作为新生成场景。
4. 逐句回看图片删除无依据形容词和矛盾细节。

## 提示词或操作规格

将当前需求组织为“目标；输入材料及其角色；修改范围；必须保留；相机/尺度；材料与光照（适用时）；交付格式”。只包含本任务相关项。编辑底图与风格/材质/产品参考必须分开标注。用户明确要求精确保留时，写入可验证的合成或模型操作方案。

示例调用：`使用 $evai-image-to-prompt，把这张客厅照片转成中文出图提示词，保留构图、材料和光照特点。`

## 输出与验收

提示词对应可见事实；不含伪造尺寸/品牌；推断明确标注；无需图片生成工具即可完成文字输出。

交付实际产物、关键操作或最终提示词，以及简短验收结果。保留原件，结果另存用户项目目录；只有提示词或中间预览时明确未完成最终产物。记录输入、工具/方法、实际输出尺寸或模型格式、通过项和未通过项，不要求为一次性任务额外建立复杂台账。

## 失败处理与边界

无法查看图片时请求可读取文件或说明阻塞；不只根据文件名编写图像内容。

修订必须针对具体缺陷；连续两次修订仍有同一核心缺陷时停止盲目重试，保留最佳结果并说明所需补图、模型或工具。用户明确要求继续时更新方案和成本边界。运行外部付费服务、上传用户材料等遵守该任务已有授权；本 Skill 不授权注册、充值、发布或购买模型。没有额外用户请求时不访问 Evai 网站。
