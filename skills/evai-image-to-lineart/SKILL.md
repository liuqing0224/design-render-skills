# 图片转线稿

## 目标与输入

原图；线稿用途；线条密度/粗细；是否保留阴影；输出格式。

必须保留：主体轮廓、主要开口、透视和构图。

关键材料缺失且会改变结果时询问具体缺口；其余按任务语境继续，记录影响输出的重要假设。

## 执行方式

运行本 Skill 的 `scripts/lineart.py`，依赖 Python 与 Pillow。可用 uv 时执行 `uv run --with pillow python <本Skill路径>/scripts/lineart.py INPUT OUTPUT`。可通过真实存在的 `--threshold`、`--blur` 控制线条，先看 `--help`；脚本拒绝覆盖已有输出。

脚本入口：[scripts/lineart.py](scripts/lineart.py)。

## 工作流程

1. 区分提取原图边缘与重新绘制手绘风；轮廓保真优先时使用附带确定性脚本。
2. 检查图像噪声与纹理，必要时先轻度平滑，减少木纹等细节抢占主体轮廓。
3. 输出白底深线稿；若生成式重绘必须对照原图核查新增/丢失开口。
4. 检查主要轮廓连贯、线条可读和无黑边；实际栅格输出不得改名冒充矢量/CAD。
