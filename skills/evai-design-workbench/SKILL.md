# 设计表现工作台

使用 Codex 当前可用工具直接执行。Evai 是功能来源，不是运行依赖，不自动访问网站、充值或上传用户素材。

## 选择与输入

读取[功能路由表](references/catalog.md)，只加载与用户任务直接相关的 Skill。已有项目使用其真实文件和规范；不强制用户迁移项目。

先明确交付类型：意向图、保真编辑、彩平图、产品图、真实三维模型或图片文件处理。编辑任务至少需要底图和具体修改目标；尺寸、相机或隐藏面缺失时区分可继续的概念表达与被阻塞的精确任务。

## 执行顺序

1. 保存原件，标记输入角色：编辑底图、结构证据、风格参考、材质参考、产品身份参考。
2. 先锁定几何、布局或产品身份，再做整体渲染/风格调整；只有局部修改时直接调用对应局部 Skill，避免不必要的整图重绘。
3. 每次只传递当前已验收的图像/模型与保留清单。场景变化后再处理局部、人物、氛围，最后按用户要求调整尺寸或压缩。
4. 多视角优先从同一三维模型渲染；单图视角推断明确隐藏区不确定性。工程图需要准确线稿/模型，不用自由生成图替代。
5. 保存实际结果，读取文件核验尺寸、格式、alpha或模型，并打开视觉检查；只运行提示词分析不能报告完成了图片。

选择路线时区分：增加像素→清晰度放大；优化材质→细节提升；减小文件→压缩；扩展画布→扩图；改变视角→同模型相机或明确推断。无损压缩不包含缩图。家具精确换款优先产品像素合成，整间风格迁移允许的改动以用户任务为准。

## 工具与停止条件

生成/编辑使用当前可用 imagegen 能力；确定性处理使用相应 Skill 的本地脚本；三维必须导出并重新读取真实模型。遵守当前用户授权和实际工具输入契约，不固化模型版本与未核验的API参数。

连续两次修订仍出现相同核心失败时停止盲目重试，交付最佳版本、失败项与所需补图/模型/工具；用户明确要求继续时调整方案再执行。用户只要求一个步骤时不自动运行整条流程。

## 交付

返回产物、简短处理说明和实际验收结论。原件、选中结果和必要的复现参数保留在用户项目目录。事实、生成推断和缺口分别说明；不把视觉表现当作尺寸、结构安全、规范合规或材料性能证明。

这些工作流依据2026-10-28提取的43个网站分类条目设计，对应36个功能Skill。已编写的操作流程不代表模型生成质量已经验证。
