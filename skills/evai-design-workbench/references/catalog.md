## 常见组合

- 毛坯房装修：毛坯装修 → 必要的家具/材质替换 → 氛围转换 → 尺寸交付。
- 建筑白模：模型渲染或建筑渲染 → 局部渲染 → 按需环境/人物 → 尺寸交付。
- 彩平：室内彩平或总彩平 → 原线稿/标注叠回 → 文件检查，不先做自由重绘。
- 产品图：抠图 → 室内棚拍或室外场景 → 产品身份核对 → 尺寸/体积交付。
- 多视角：有模型时先从同模型生成所需相机；无模型时说明视角推断，不承诺跨视角几何一致。
- 图转3D：主体输入检查 → 真实模型重建/参数化建模 → 模型重开与转动检查；渲染图不算模型。
