# AI模型渲染

## 目标与输入

模型文件或清晰截图；室内/建筑/景观类别；已有材质贴图；相机；需要保留和可调整的内容。

必须保留：体量、层数、墙体、门窗开口、家具位置、相机透视和已确认材质。

关键材料缺失且会改变结果时询问具体缺口；其余按任务语境继续，记录影响输出的重要假设。

## 执行方式

优先用真实模型和当前可用渲染器执行，保留相机、网格与贴图。只有截图辅助表现或明确需要生成式图像时，才使用以下生图路线。

读取当前环境可用的 `imagegen` Skill，按实际工具说明执行；本地编辑目标先加载到视觉上下文。优先内置图像工具。若不可用，检查当前环境是否存在用户已授权的替代工具；只有工具可用且授权明确时才执行。先核实命令、输入输出契约与认证状态，不输出凭据，不假设其他机器已有相同配置或授权，不擅自切换供应商。蒙版、尺寸、参考图等字段只使用工具实际支持的参数。

生成后必须打开结果检查。用户要求区域外像素不变时，采用可验证的局部合成；生成式模型本身不提供这种保证。工具不可用则明确交付“待执行方案”，不以提示词代替已完成图像。

## 工作流程

1. 检查是否拿到真实模型，记录单位、坐标轴、相机和贴图路径；只有截图时标为图像辅助表现。
2. 有可用三维渲染器时直接读取模型、修复缺失贴图并布光；否则将截图作为编辑目标，材质样板作为材质参考。
3. 室内核对墙角、窗洞与家具；室外核对体量、屋顶和立面分格。只调整获准的光照、曝光与表现质量。
4. 保存源模型版本、相机和材质清单；AI编辑结果与源图并排复查。

## 提示词或操作规格

将当前需求组织为“目标；输入材料及其角色；修改范围；必须保留；相机/尺度；材料与光照（适用时）；交付格式”。只包含本任务相关项。编辑底图与风格/材质/产品参考必须分开标注。用户明确要求精确保留时，写入可验证的合成或模型操作方案。

示例调用：`使用 $evai-model-render，把这张室内白模截图渲染为写实效果，保留门窗和家具位置，使用附带的木材与石材样板。`

## 输出与验收

模型路线可打开且贴图可解析；图像路线没有明显体量/开口漂移；不得把视觉相似表述为像素级贴图保真。

交付实际产物、关键操作或最终提示词，以及简短验收结果。保留原件，结果另存用户项目目录；只有提示词或中间预览时明确未完成最终产物。记录输入、工具/方法、实际输出尺寸或模型格式、通过项和未通过项，不要求为一次性任务额外建立复杂台账。

## 失败处理与边界

贴图丢失则列出缺失材质并保留白模预览；几何保真不合格则退回真实模型渲染；无三维输入不承诺测量精度。

修订必须针对具体缺陷；连续两次修订仍有同一核心缺陷时停止盲目重试，保留最佳结果并说明所需补图、模型或工具。用户明确要求继续时更新方案和成本边界。运行外部付费服务、上传用户材料等遵守该任务已有授权；本 Skill 不授权注册、充值、发布或购买模型。没有额外用户请求时不访问 Evai 网站。
