# 提示词扩词

## 目标与输入

原始需求；生成/编辑任务；参考图（如有）；必须保留与禁止内容；输出语言。

必须保留：用户具体指定的物件、材料、数量、位置和文字。

关键材料缺失且会改变结果时询问具体缺口；其余按任务语境继续，记录影响输出的重要假设。

## 执行方式

直接读取用户提供的材料进行图像理解或文字编写；只在用户进一步要求实际出图时使用图像生成工具。不要为提示词任务制造额外生图成本。

## 工作流程

1. 判断是无底图生成还是基于底图编辑，提取目标和不能改变的内容。
2. 只补足执行所必需的场景与表现描述；用户已详细说明时主要做结构化。
3. 按目标、输入角色、相机、材料、光照、保留项组织，避免互相矛盾的风格和多余参数。
4. 返回可直接使用的提示词并单列重要假设；用户只要提示词时不调用生图工具。

## 提示词或操作规格

将当前需求组织为“目标；输入材料及其角色；修改范围；必须保留；相机/尺度；材料与光照（适用时）；交付格式”。只包含本任务相关项。编辑底图与风格/材质/产品参考必须分开标注。用户明确要求精确保留时，写入可验证的合成或模型操作方案。

示例调用：`使用 $design-prompt-expand，把“这个卧室更温馨一点”扩写成编辑提示词，保持布局、家具和窗户。`

## 输出与验收

原始意图完整保留；无新增品牌和额外物件；编辑提示明确改哪里、保留哪里；不把提示词参数当真实API字段。

交付实际产物、关键操作或最终提示词，以及简短验收结果。保留原件，结果另存用户项目目录；只有提示词或中间预览时明确未完成最终产物。记录输入、工具/方法、实际输出尺寸或模型格式、通过项和未通过项，不要求为一次性任务额外建立复杂台账。

## 失败处理与边界

缺少会改变结果的关键目标时提一个具体问题；其余可合理补足的表现细节明示即可。

修订必须针对具体缺陷；连续两次修订仍有同一核心缺陷时停止盲目重试，保留最佳结果并说明所需补图、模型或工具。用户明确要求继续时更新方案和成本边界。运行外部付费服务、上传用户材料等遵守该任务已有授权；本 Skill 不授权注册、充值、发布或购买模型。

## 验证状态

工作流定义与有限样本测试分别记录。受控样本结论见仓库测试报告；未测试的输入、功能分支和生成质量需在实际任务中验证。
