# 清晰度放大

## 目标与输入

原图；目标宽高或倍率；长宽比；是否允许AI补细节；最终格式。

必须保留：构图、长宽比（除非另有裁切要求）、物件、文字和透明通道。

关键材料缺失且会改变结果时询问具体缺口；其余按任务语境继续，记录影响输出的重要假设。

## 执行方式

运行本 Skill 的 `scripts/upscale.py`，依赖 Python 与 Pillow。先核实解释器；可用 uv 时执行 `uv run --with pillow python <本Skill路径>/scripts/upscale.py INPUT OUTPUT --width 3840`。脚本不会调用生图服务。具体输入输出路径必须实际替换，输出默认不得覆盖现有文件。

脚本入口：[scripts/upscale.py](scripts/upscale.py)。

## 工作流程

1. 读取真实像素、色彩模式、透明度与方向；将“4K”等表述转成明确目标尺寸。
2. 保真放大使用附带LANCZOS脚本；要求AI超分时先发现实际可用工具，并说明细节可能推断。
3. 按比例缩放，用户没有允许时不拉伸或裁切；保留色彩配置与alpha。
4. 检查实际宽高、文字、细线、锐化光晕与透明边缘；记录所用方法。
