# 无损压缩

## 目标与输入

输入图片；目标文件体积（如有）；像素尺寸是否锁定；可否有损；输出格式。

必须保留：默认原像素、宽高、alpha和颜色配置；用户明确放开某项时才调整。

关键材料缺失且会改变结果时询问具体缺口；其余按任务语境继续，记录影响输出的重要假设。

## 执行方式

运行本 Skill 的 `scripts/compress.py`，依赖 Python 与 Pillow。可用 uv 时执行 `uv run --with pillow python <本Skill路径>/scripts/compress.py INPUT OUTPUT`。仅在用户允许缩图时附加 `--max-width` 或 `--max-height`；先运行 `--help` 查看实际参数。脚本拒绝覆盖已有输出。

脚本入口：[scripts/compress.py](scripts/compress.py)。

## 工作流程

1. 读取输入格式、实际字节数、尺寸、像素模式和alpha；将无损作为默认约束。
2. PNG使用附带脚本优化并核对解码像素；JPEG/WebP默认复制原文件，不谎称重新有损编码是无损。
3. 文件未变小时保留原件并如实报告；体积硬上限需要有损或缩图时先明确用户允许的选择。
4. 若允许缩图，单独按宽高重采样并标为缩图模式；报告前后字节数、尺寸和像素变化。
