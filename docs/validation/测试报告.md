# 设计出图 Skills 功能测试

样本执行：2026-10-28。名称与文档整理：2026-10-29；此次未重新生成图像。

## 测试范围与结果

- 36个功能各执行1个受控样本：**17项样本通过、17项部分通过、2项未通过**。通过只针对本例明确测试的目标，不代表全部输入和分支通过。
- 27个生成式图像功能实际运行，另有3个脚本处理、2个分区彩平、2个文字案例、1个抠图与1个参数化三维案例。3个本地图片脚本的11项行为测试通过。
- 工作台调度Skill做了人工流程走查，未验证新会话自动触发率，未做独立Agent行为评估。

## 影响使用的限制

1. **放大仅验证插值**：LANCZOS将1254×1254放大为2508×2508，没有验证AI细节恢复。
2. **局部编辑依赖合成**：首次室内局部输出在蒙版外约99.11%像素发生变化，MAE约6.14/255，不意味着99.11%语义内容改变。将石材范围合成回原图后，区域外变化像素为0。室外局部修改、物体移除等未补做合成，判部分通过。
3. **扩图未通过**：原图1254×1254，原始横图1536×1024改变主体尺度；恢复原图像素后的1881×1254诊断合成有明显接缝。两个版本均保留。
4. **空房装修未通过**：1000×700草图输出1254×1254，房间比例与门窗关系改变。生成了装修意向，未通过结构保留要求。
5. **三维只有近似路线**：实际导出并重新读取GLB，5个封闭网格、444三角面；依据参考人工推断并参数化建模。三视角可见椅壳方折、腿端穿壳，不是自动AI重建或精确产品模型。
6. **产品保真与抠图有限**：家具与拼图样本的木纹、椅壳或沙发细节被重画。抠图有真alpha且保留原RGB，但椅脚周边有白斑与残留阴影；复杂背景尚未测试。
7. **压缩收益有限**：PNG从1,880,460减至1,806,117字节，少74,343字节，约3.95%；尺寸和像素不变。不保证任意图片都能明显缩小。

## 方法与证据边界

输入包括原创合成室内图、两层四窗建筑、青色四腿椅、人工平面和空房草图，不含真实客户项目。按Skill主路线组织提示，并使用原测试环境中既有授权的工具；认证与机器配置不随仓库分发。工具返回未标明实际模型名称，因此不主张某一指定模型已通过。输出一般为1254×1254；请求1024×1024未总被遵守，以读取文件为准。

人工审查主体、数量、门窗、布局、产品身份与明显瑕疵。确定性检查包括尺寸、字节数、alpha、线条像素保留、区域外像素差与模型重读。人工分区、蒙版和参数化建模不等于自动识别或自动重建。每项仅一个受控案例，未测随机稳定性、速度、费用、并发、全部风格、全部格式和真实项目。

输入、产物、主要提示与验收指标见[图文报告](测试报告.html)、[测试矩阵 JSON](功能测试矩阵.json)和[evidence](evidence)。原始生成、补救合成和失败样本均保留；文件改名没有修改图像或模型内容。

## 调度走查与后续验证

人工走查六种请求的路线：只变宽高→放大；只减字节→压缩；向两边补画→扩图；只改墙面→局部编辑及蒙版合成；家具透明素材→抠图后棚拍；交付GLB→真实建模、导出与重读。工作台与路由表能区分这些任务，但未证明自然语言自动触发准确率。

优先修复扩图画布、原尺度与接缝，以及空房装修画幅与几何保留；增加局部合成、产品像素保留路线，再用同输入回归并增加实拍、复杂背景和精确产品案例。

2026-10-29整理统一了37个Skill的名称、示例调用、文档与引用，功能流程及脚本算法保持。原有限样本结论继续适用；格式、脚本行为与安装检查不替代视觉效果验证。
